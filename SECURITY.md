# Security Policy

## Reporting a Security Issue

If you discover a potential security vulnerability, please do not publicly disclose sensitive details in a GitHub issue.

Instead, contact the repository maintainer privately through GitHub with enough information to reproduce and understand the issue.

## Scope

Please report issues involving:

- Exposure of secrets or credentials
- Unsafe handling of user input
- Dependency-related security vulnerabilities
- Unexpected access to files or system resources
- Other behavior that could compromise users or the application

For ordinary bugs and feature requests, please use GitHub Issues.
